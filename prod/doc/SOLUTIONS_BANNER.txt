📈 WHAT HAPPENS AUTOMATICALLY:

  1. PostgreSQL database starts
  2. App container initializes  
  3. Waits for PostgreSQL (max 30 seconds)
  4. Data cleaning (01_data_cleaning.py)
     ↓ Loads data from database
     ↓ Applies feature engineering
     ↓ Normalizes values
  5. Model training (02_train_models.py)
     ↓ Random Forest (30-60s)
     ↓ LSTM neural network (60-180s)
     ↓ ARIMA time series (30-90s per symbol)
     ↓ SARIMAX time series (60-120s per symbol)
  6. Models saved to /models/ directory
  7. API loads models into memory
  8. FastAPI server starts on port 8000
  9. Ready for predictions!
